What is an OTG adapter?

OTG stands for “On-The-Go”. An OTG adapter is a small connector that enables an Android phone to read from and write to a standard USB drive.

When do you need one?

  • A standard, wide USB-A drive does not fit directly into the phone’s USB-C port. You need the adapter for this.
  • If your drive already has a USB-C connector, or both connector types, you do not need an additional adapter.
  • A USB-C hub with a USB-A port also works if it supports data transfer.
Useful search term: “USB-C OTG to USB-A adapter — data transfer”

Important: A charging-only adapter is not sufficient. The description should explicitly mention OTG or data transfer.

Step-by-step instructions

The screenshots show the actual FotoSafe interface and Samsung file picker. Labels may vary slightly depending on the manufacturer and Android version.

Actual FotoSafe screen on a Samsung Galaxy S23.

1

Connect the USB drive

Connect a USB-C drive directly. For a standard USB-A drive, use a data-capable USB-C OTG adapter. Then wait a few seconds.

  • Unlock the phone.
  • Open FotoSafe.
  • Under Select, tap “Change backup location”.

“Galaxy S23 › Test” is still selected here — this is intentionally the incorrect example.

2

Check the storage shown at the top

The Android file picker often opens in the last folder used. First check the name at the top or in the path bar.

  • “Galaxy S23” means the phone’s internal storage.
  • “Test”, “Downloads” and “DCIM” may also be folders on the phone.
  • Do not confirm anything until the USB storage device is clearly identified.

If only the phone appears as a storage location, FotoSafe cannot select the USB drive.

3

Open the USB storage

In the storage location picker, switch to the USB storage device. Depending on the device, it may appear as USB drive, USB storage device, the manufacturer’s name or its assigned volume name.

On some Android versions, use the menu at the top left. On Samsung devices, the USB storage may appear directly as a separate location. If only the phone name remains visible, go to “USB drive is not shown”.

4

Confirm a folder on the USB drive

Open the USB drive. If the button is active, you can select the USB drive’s root folder. If Android does not allow this:

  • Tap “Create new folder”.
  • For example, name it “Backup”.
  • Open this folder and tap “Use this folder”.
  • Then confirm Android’s access request by tapping “Allow”.

FotoSafe automatically creates its own FotoSafe folder in the selected location.

Check before confirming

✓The USB storage device, not the phone, is shown at the top.
✓The “Use this folder” button is active.
✓You are selecting a folder, not individual photos or videos.
5

Check again in FotoSafe

After selection, FotoSafe shows the chosen backup location under “Destination”. Check the name again before tapping “Check selection” and then starting the backup.

Important: Do not disconnect the drive or adapter during the backup. Afterwards, check important backups directly on the USB drive.

Remember

If the phone name appears at the top, you are in the wrong storage location. If the USB storage device appears there, you can use the folder.

USB drive not shown?

If Android does not offer the drive as a storage location, FotoSafe cannot select it either. Follow these steps in order to avoid unnecessary formatting.

1. Reconnect the drive

  • Close the file picker.
  • Disconnect the drive and adapter.
  • Reconnect them firmly.
  • Wait a few seconds and reopen FotoSafe.

2. Check with “My Files”

Open Samsung’s “My Files” app or your manufacturer’s file manager. If the USB drive is not shown there either, the issue is not caused by FotoSafe.

3. Check the adapter and power requirements

Try another data-capable OTG adapter or a smaller USB drive. Some drives require more power than the phone can reliably provide.

4. Check the file system

exFAT is suitable for large videos and commonly works with Android, Windows and macOS. FAT32 has a 4 GB per-file size limit.

Format only as a last resort

Warning: Formatting deletes every file on the USB drive. Back up existing data to another storage device first. Never format a drive merely as a guess.

Test the drive and adapter on another Android device or computer. More support help
